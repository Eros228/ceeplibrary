Manual de Uso - CEEP's Library

1. Pesquisa Inteligente: Utilize a barra de pesquisa no topo para encontrar livros por título ou para pesquisar por nome de aluno ou turma que esteja com algum livro emprestado.

2. Cadastrar Livros: Clique no botão de mais (+) no cabeçalho. Você pode digitar o nome do livro para buscar capas automaticamente via Open Library/Google Books, carregar uma imagem do seu dispositivo ou colar uma URL direta da imagem.

3. Emprestar Livros: Em cada card, clique no botão Emprestar para registrar o nome do aluno, turma, data de empréstimo e a data prevista para devolução (limite máximo padrão de 15 dias).

4. Devolução de Exemplares: Clique no botão Empréstimos do livro correspondente para ver todos os alunos que estão com ele e clique em Devolver para liberar o exemplar de volta para o acervo.

5. Alterar quantidade total: Clique no número total exibido no card do livro para definir a nova quantidade exata de exemplares (não é somado ao valor anterior).

6. Visualizar Emprestados: Alterne para a aba Apenas Emprestados no menu superior para visualizar rapidamente o resumo de todas as obras fora da biblioteca e quais alunos as detêm.
